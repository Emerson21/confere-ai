# Confere Aí — MVP WebApp (Tech4Change FIAP 2026)

> Assistente inteligente contra desinformação e golpes digitais: *"Antes de acreditar, clicar ou compartilhar, confira."*

---

## 🎯 Sobre o Projeto

O **Confere Aí** é um WebApp mobile-first projetado para orientar pessoas — especialmente com menor familiaridade digital — a analisar mensagens, links, cobranças e comprovantes suspeitos antes de agir ou compartilhar.

- **Sanitização de PII**: Proteção de dados sensíveis (CPF, telefones, e-mails, chaves Pix) antes de qualquer envio a LLMs.
- **RAG & Fact-Checking**: Checagem de evidências com APIs de verificação (ex: Google Fact Check Tools) e análise de engenharia social.
- **Transparência Pedagógica**: Veredito conciso com expansão de detalhes, fontes e checklist prático de ação.
- **Segurança sem Falsa Certeza**: Classificações orientadas a risco (`BAIXO_RISCO`, `SUSPEITO`, `ALTO_RISCO`, `INCONCLUSIVO`), nunca declarando "100% seguro".
